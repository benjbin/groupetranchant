Le Rideau

TRANCHANT est une scène. Chaque plein de ses lettres est un pli de velours — trois lamelles séparées par deux jours de lumière qui se referment dans les déliés — et chaque barre est une tringle. Le nom ne s’affiche pas : il se lève, et la lumière passe entre ses plis.

LigaturesTR · AN · AN · NT — le mot s’accroche en haut, se pose en bas, se referme en haut : une symétrie de scène.

Rideau fermé · < 24 px

Les lamelles sont un détail de grand corps. Sous 24 px de hauteur de capitale (en-têtes, signatures mail, gravure fine), le rideau se ferme : les pleins redeviennent pleins, le dessin des lettres ne change pas. Monochrome sans dégradé, sans trame : le logo se grave, se brode, se marque à chaud.

iii.

Symbole

Ligature TR · coupe « symbole »

Le symbole n’est pas inventé : il est découpé dans le mot. Les deux premières lettres, liées par la tringle, forment un portant de scène.

Coupe dédiée aux petites tailles : plein 84, jours 13, délié 26 (contre 60 / 3,6 / 12 dans le mot). À 32 px les plis restent lisibles comme une texture ; à 16 px ils se fondent, la silhouette TR demeure.

iv.

Construction

  1. Le pli. Chaque plein est découpé en trois lamelles égales séparées par deux jours (17,6 + 3,6 + 17,6 + 3,6 + 17,6 = 60). Dans les courbes, les jours se resserrent avec l’épaisseur et disparaissent dans les déliés : les plis convergent comme un velours retenu.
  2. La tringle. Toute horizontale est un délié de 12. La barre du T porte les lamelles comme une tringle porte le rideau.
  3. La didone étroite. Axe vertical, contraste de 5 pour 1, rondes en superellipse (n = 3) qui dépassent de 6, becs verticaux sur le C, A à sommet plat, N à diagonale pleine.
  4. L’approche. Espaces optiques : 56 entre deux fûts, 30 contre une ronde, 10 entre deux pieds obliques. Les ligatures remplacent les approches impossibles (TR, AN, NT).
